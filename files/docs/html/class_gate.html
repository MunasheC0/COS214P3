Detailed Description

An entry gate that admits visitors and locks down when told to.

Leaf (GoF Composite) and ConcreteObserver (GoF Observer), via EventUnit. The two roles serve separate collaborations: as a leaf it sits in the festival tree; as an observer it stops admitting on CLOSE/EVACUATE and reopens on OPEN/RESUME. While not admitting, it reports a capacity of 0.
