Detailed Description

Abstract base for all single (non-group) festival units, providing the shared default behaviour for opening, closing and reporting.

Leaf base (GoF Composite) and Observer (GoF Observer). These are two separate collaborations, not a duplicated pattern: as an EventComponent it is a childless node in the Composite tree, while as an EventObserver it can be attached to a subject and receive notices. update() stays pure virtual so each concrete leaf defines its own reaction.
