Detailed Description

Plain data object describing a single event notification.

Not a GoF pattern participant itself — it is the parameter object passed from subjects into EventObserver::update() (and through EventSubject/EventControl::notify()), bundling what happened (type), a human-readable message, and how urgent it is (severity).
