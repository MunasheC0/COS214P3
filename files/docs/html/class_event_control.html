Detailed Description

Top-level festival coordinator that issues notices to its registered observers.

ConcreteSubject (GoF Observer). EventControl is deliberately NOT part of the Composite tree — it is not an EventComponent and has no capacity or open/closed state; it only originates notifications. It holds its observers through non-owning pointers and never deletes them.

◆ attach()

void EventControl::attach ( EventObserver * observer)

Registers an observer for future event notifications.

EventControl stores a non-owning pointer. The observer must remain alive while registered and must be detached before destruction. A pointer that is already registered is ignored, so an observer is never notified twice for one notice.

Parameters
observerEventObserver to register. Must not be nullptr (a nullptr argument is ignored).

◆ detach()

void EventControl::detach ( EventObserver * observer)

Unregisters a previously attached observer.

Only the stored pointer is removed; the observer itself is never deleted — the caller retains full ownership. Detaching an observer that was never attached is a silent no-op.

Parameters
observerEventObserver to remove. May be a pointer that was never attached; nullptr is ignored.

void EventControl::notify ( Notice & notice)

Delivers a notice to every currently attached observer.

Observers are called in the order they were attached, via EventObserver::update(). Attached RelayGroups forward the notice further down their subtrees.

Parameters
noticeThe notice to broadcast. Not modified or stored by EventControl itself.
